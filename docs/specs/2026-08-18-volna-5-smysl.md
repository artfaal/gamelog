# Волна 5 — смысл записей и фичи из готовых данных

Дата: 2026-08-18 · Источник: аудит 7 каналов (см. `docs/specs/README.md`)

## Результат

Дневник перестаёт врать читателю и показывает то, что Steam уже отдал, а
сборка выбрасывала. Сейчас три записи с текстом «вернусь» и `score: tbd` числятся
пройденными, потому что «пройдено» — это всё, что не дроп и не «сейчас играю». Чип «кооп»
приезжает из категории Steam и означает «игра поддерживает кооператив», а не «этот заход
был совместным» — то есть приписывает записи факт, которого в ней нет. Плюс две вещи
из готовых данных: дата выхода игры
(Steam отдаёт её по всем записям, `appCache` выбрасывает) и фид.

## Приёмка

1. **B1.** Появляется статус «отложил»: `grep -c 'paused' scripts/build.mjs` → не `0`.
   Caves of Qud, Pacific Drive и Subnautica 2 больше не попадают в срез «пройдено».
   В полке у них своя группа или чип. Записи без нового поля ведут себя как сейчас.
2. **B2.** Чип перестаёт врать. Либо переименован в «есть кооп», либо заменён на факт из
   фронтматтера (`with:` — с кем играл). Если выбран второй путь: записи без этого поля чип
   не получают, а поле проставлено хотя бы по тем записям, где совместная игра
   действительно была.
3. **F1.** `grep -c 'released\|release_date' scripts/steam-app.mjs` → не `0`.
   В мете записи виден год выхода и разрыв с датой прохождения. Проверка на краях:
   Dead Cells — «вышла в 2018 · через 7 лет»; Space Haven — разрыв 12 дней, формулировка
   не должна выглядеть нелепо; запись с `finished: tbd` — только год выхода, без разрыва;
   не-Steam запись без кэша — чипа нет, сборка не падает.
   Чип откачен волной 6 — `docs/specs/2026-08-19-volna-6-priyomka.md`; поле `released`
   в кэшах и в `SAFE` осталось, возврат отображения — `git show e099a78 -- scripts/build.mjs`.
4. **F7.** `dist/feed.xml` существует, валиден (проверить любым RSS-валидатором или
   `xmllint --noout`), содержит все опубликованные записи с `pubDate` из `finished`,
   `link` на стаб `/e/<slug>/`. Черновики в фид не попадают. Ссылка на фид есть в `<head>`
   (`<link rel="alternate" type="application/rss+xml">`).
5. **N1.** В бэклог README дописана гистограмма распределения оценок с пометкой, что она
   ждёт роста числа записей.
6. `make build` проходит на всех 17 записях, `make check` чист. `make refresh` по-прежнему
   работает и видит новое поле кэша.

## Не делаем

- **Не делаем очередь «что дальше»** (F4 отклонён): `add_game.md` наружу не выходит.
- **Не вводим поле `started:`** (F5 отклонён).
- **Не тянем достижения Steam** (F6 отклонён).
- **Не правим вердикт Crimson Desert** (B3): расхождение 16 против 19 часов уже устранено
  в рабочем дереве — вердикт заменён на «Красиво. Медленно. Мимо.».
- **Не делаем шкалу HowLongToBeat** (F2): прототип показал, что источника нет — HLTB за
  Cloudflare отдаёт 403 и напрямую, и через прокси, официального API у них нет, SteamSpy
  время игры больше не отдаёт (`median_forever: 0`). Фича превращалась бы в ручное поле
  на каждую запись, и у 7 игр из 17 (рогалики и песочницы) понятия «сюжет за N часов»
  не существует вовсе. Отклонено после прототипа.
- **Не делаем сводку «Хроника целиком»** (F3): прототип отклонён автором.
- Не переписываем `shots` и `micro` в кэшах — они ломают записи молча (README).

## Изменяемые контракты

- **Фронтматтер записи.** Добавляется необязательное `paused: true`. Несовместимо
  с `dropped: true` и с `finished: tbd` — сборка обязана ругаться на сочетание, как она
  уже ругается на дроп с `finished: tbd`. Возможно добавляется `with:`.
- **`cache/<appid>.json` — форма кэша.** Добавляется `released` (строка даты от Steam,
  формат их, не наш). Существующие 25 файлов поля не имеют — сборка обязана работать
  без него. Пишет `appCache()` в `scripts/steam-app.mjs`; `refresh.mjs` подхватывает
  автоматически, форма у них общая. Поле приезжает тем же запросом `appdetails`,
  которым уже берутся жанры, — новых походов в сеть нет.
- **`dist/feed.xml`** — новый публичный URL. Меняется `<head>` главной. В `sitemap.xml`
  фид не добавляется: там намеренно один URL — корень.
- **README.** Описываются `paused:`, `with:`, `released` и фид. Бэклог обновляется:
  RSS уходит из него в сделанное, гистограмма приходит.

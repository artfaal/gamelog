# Волна 1б — отдача статики (nginx на orion)

Дата: 2026-08-18 · Источник: аудит 7 каналов (см. `docs/specs/README.md`)

## Результат

Сервер перестаёт отдавать текст сырьём и заставлять браузер перепроверять каждый файл при
каждом заходе. Сейчас ни один ответ не несёт `content-encoding`: HTML 101 971 байт,
`styles.css` 38 419, `app.js` 15 090 — итого 155 КБ, которые gzip сжимает до 31 КБ.
`Cache-Control` не стоит нигде: есть только `etag` и `last-modified`, поэтому повторный
заход — это 38 условных запросов, каждый с полным RTT. После правки текст едет впятеро
легче, а повторный заход не тянет заново неизменившиеся ассеты.

Правка живёт **вне репозитория** — в конфиге nginx на orion. Поэтому она вынесена из
волны 1 отдельной спекой: у неё другое место правки, другой способ приёмки и другой откат.

## Приёмка

1. `curl -sI -H 'Accept-Encoding: gzip, br' https://games.artfaal.ru/` содержит
   `content-encoding: gzip` (или `br`).
2. То же для `/styles.css` и `/app.js`.
3. `curl -sI https://games.artfaal.ru/a/<любой-ассет>.jpg` содержит
   `cache-control: public, max-age=31536000, immutable`.
4. То же для файла из `/fonts/`.
5. `curl -sI https://games.artfaal.ru/` содержит `cache-control` с `no-cache`
   (или `max-age=0, must-revalidate`) — HTML не должен залипать: он меняется каждой сборкой.
6. `curl -s https://games.artfaal.ru/ | head -c 200` по-прежнему отдаёт валидный HTML,
   сайт открывается в браузере, шрифты и арт на месте.
7. Приём с чистым кэшем: суммарный вес запросов первого захода на десктопе уменьшился
   относительно замера до правки. Метод — `performance.getEntriesByType('resource')`.
8. `README.md` в разделе «Инфраструктура» описывает обе настройки — иначе они не зафиксированы
   нигде и потеряются при следующем переезде.
9. INFRA-DOCS `servers/orion.md` обновлён следом (правило из `~/.claude/CLAUDE.md`:
   менял инфру — дока обновляется тем же заходом).

## Не делаем

- Не трогаем содержимое репозитория `gamelog`, кроме раздела «Инфраструктура» в `README.md`.
- Не вводим CI и не автоматизируем деплой конфига — `make deploy` остаётся `rsync`,
  CI в проекте нет намеренно.
- Не включаем brotli, если модуль не собран в этом nginx: gzip даёт основной выигрыш,
  а пересборка nginx ради нескольких килобайт не окупается.
- Не ставим долгий `max-age` на HTML: он меняется каждой сборкой.

## Изменяемые контракты

- **nginx vhost gamelog на orion**, `/var/docker/compose/gamelog/`. Добавляются директивы
  `gzip on; gzip_types text/html text/css application/javascript image/svg+xml;
  gzip_min_length 1024;` и два `location` с заголовком `Cache-Control`.
- **Откат**: вернуть прежний конфиг и перечитать (`nginx -s reload` внутри контейнера
  либо перезапуск сервиса compose). Правка не касается данных, только заголовков ответа.
- **Риск**: `immutable` на `/a/` верен, пока ассеты адресуются именем файла от Steam и
  не перезаписываются под тем же именем. Сборка кэширует ассет по имени файла, а метку
  `?t=…` расхождением не считает — то есть имя стабильно. Если это перестанет быть верным,
  `immutable` будет отдавать читателю устаревшую картинку весь год, пока не истечёт `max-age`.

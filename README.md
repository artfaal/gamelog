# gamelog — «Хроника»

Дневник прохождений игр: одностраничная хроника с впечатлениями, скринами,
видео-лупами и wallpaper'ами из Steam. Личный проект Макса, публикация — на
поддомен artfaal.ru (домен обсуждается).

## Статус

Прототип UI прошёл 5 итераций отбора (варианты A…J), победитель — **I «Свиток»**:
sticky-wallpaper игры на весь экран, записи плывут поверх стеклянными панелями
по центру; оглавление-оверлей, лайтбокс, «моменты» (текст к скрину), записи-дропы
и возвращения к играм (несколько заходов с перекрёстными ссылками).

- Живой прототип: https://pub.artfaal.ru/gamelog-proto/
- Исходники прототипа: ветка `prototype` (throwaway, в main не мержится)
- Ассеты приезжают со Steam CDN по appid: `library_hero.jpg`,
  `library_600x900_2x.jpg`, `logo.png`; скрины/трейлеры — через appdetails API
  (`cc=us&l=english`), прямые видео — `cdn.akamai.steamstatic.com/steam/apps/<movieid>/microtrailer.webm`

## Целевая архитектура (обсуждается на грилле)

- Контент: по markdown-файлу на запись с YAML-frontmatter (appid, даты, часы,
  оценка, статус done/dropped, связки заходов), тело — впечатление и «моменты».
- Генератор статики — максимально простой; критерий №1: **ПРОСТО поддерживать**.
- Перед релизом: визуальное ревью фронтендер-агентом в браузере на разных
  разрешениях.
